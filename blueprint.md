# Project Blueprint

## Overview

This project is a web application for Mawego Engineering Polytechnic. It includes features like an AI Tutor, a career portal, discussion forums, and student/faculty portals. The goal is to create a comprehensive platform for students, faculty, and administrators.

## Implemented Features

*   **Firebase Integration:** The project is connected to Firebase for authentication, database, and other services.
*   **User Authentication:** Students, faculty, and administrators can sign up and log in to the application.
*   **AI Tutor:** An AI-powered tutor to assist students with their studies.
*   **Career Portal:** A portal for posting and applying for jobs.
*   **Discussion Forum:** A place for students and faculty to engage in discussions.
*   **Student Portal:** A dedicated portal for students to access their courses, resources, and profile.
*   **Faculty Portal:** A dedicated portal for faculty to manage courses, resources, and their profile.
*   **PWA Support:** The application is a Progressive Web App, allowing it to be installed on users' devices.
*   **Modern UI/UX:** The application features a modern and visually appealing design.
